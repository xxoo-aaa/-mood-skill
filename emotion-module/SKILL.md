# 情绪模块

## ★★ 第零条之前的硬约束｜文体（不可协商）

> **必须要使用影视化 / 分镜式的微表情描写。**

**这一句是硬性规则，写在技能里，不可协商。**

**技能也要写这一条。** 本模块从这一句以下所有内容——规则、示例、对照表、起手式、自检表——
**全部服从这一句**。凡本模块任何一处文字与「影视化 / 分镜式的微表情描写」不合，**以这一句为准，那一处作废重写。**

```
情绪全靠身体演出来，不直说
✓ 她带着害羞和难过交织的情绪，嘴角想笑又轻轻抿住，眉毛微微收紧
✗ 她心里很难过，勉强笑了笑
```

**四条同时成立，缺一不可**：

| | 内容 |
|---|---|
| **必须** | **影视化 / 分镜式微表情描写**（慢镜头白描） |
| **不许** | 口语白描（往里聚・往一块儿凑・兜住・框住）——**文风不对，不是生造** |
| **不许** | 抽象状态（泪在眶里聚住・绷起来・字字往下压・嘴角上提） |
| **不许** | 部位黑话（眉内侧上提・满颊・压合半格・张到最大） |

**「必须」是命令式，不是建议式。** 写情绪时没有第二种文体可选——
不是「最好这么写」，是**只能这么写**。写出来的每一句都要能通过下面这张标尺。<!-- 文体硬约束 必须使用影视化分镜式微表情描写 -->

**为什么必须**：

> 情绪不是突然"出现"，而是像一股力，从脸部最微小的地方一路传到身体。
> 眉毛 → 眼皮 → 眼神路径 → 眨眼 → 呼吸 / 鼻翼 → 嘴唇 / 下颌 → 肩颈 → 手指 → 头部 → 重心。

**戏眼不在"她难过"，在这四段拉锯**：

```
反应 → 被本人意识到 → 试图压住 → 压住失败了一瞬 → 重新控制
```

> 因为这里面最重要的不是"她难过"，而是：
> 难过出现 → 被本人意识到 → 本人试图压住 → 压住失败了一瞬 → 又重新控制。
> 真正好看的微表情通常都有这种反应—掩饰—泄露—回收。

**分镜式还有一层**：**不是所有动作都塞在一个镜头里**——一镜只取链条上的一段。

> **每次动笔前读一遍，写完对着自检表逐条打勾。**

## ★ 第零条｜总—分结构：先给情绪，再给身体

**这一条排在最前，它决定其余所有条款能不能落地。**

**含情脉脉这类词很有用，不要小看——它本身就是生动的、可用的。**
「**他有些无奈地摇了摇头**」「**他含情脉脉地看着男主**」——**这些都可以当总分结构：
先有一个情绪及状态，再写他的表情动作。**

**⚠️ 但落到书面时，「总」要写成「带着 A 又 B」的样子，不是「XX 地 + 动词」。**

```
✗ 他有些无奈地摇了摇头            （情绪副词直接修饰动作＝总结腔）
✓ 他有些无奈又好笑地摇了摇头       （两个情绪并置，不修饰动作）
✓ 男主带着克制的笑意，轻轻摇了摇头，嘴角跟着扯了一下  （总在前，分在后）
```

**说明**：上面「他有些无奈地摇了摇头」是**口述举例**，用来讲清"总分结构"这个概念；
**落到成句时按 ✓ 那两行的形状写。**
依据：20 组范例里，「总」一律是 **`有些 A 又 B`／`带着 A 又 B`** 这种**两个情绪并置**的形状
（"有些锐利又从容""带着焦急和难以启齿的受伤"），**从不用"地"去修饰动作。**
详见 [影视化微表情写法.md](references/影视化微表情写法.md) 第三节第 1 条。

**总在前，分在后。** 也可以**分在前、总在后**——关键在两种都要有。

| 顺序 | 写法 |
|---|---|
| **总 → 分** | **男主带着克制的笑意**，轻轻摇了摇头，嘴角跟着扯了一下，没说话 |
| **分 → 总** | **他微微皱眉，抿了一下嘴**，那点笑意慢慢收了回去 |

**也可以「分—总」**：「他微微皱眉，抿了一下嘴，有些沮丧地缓慢摇头，
**配上一些形容词，还要有轻重缓急**。」

### 用「总→分」还是「分→总」

| 什么时候 | 用哪种 | 为什么 |
|---|---|---|
| 情绪先到、动作是它的结果 | **总 → 分** | 观众先知道方向，再看证据 |
| 动作先起、人物后知后觉 | **分 → 总** | 身体先泄露，情绪**追认**自己 |
| 一句话要收住 | **分 → 总** | 收在情绪词上，有落点 |

**「分→总」特别像人**：人是先皱了眉，才反应过来自己在难过。

### 轻重缓急——形容词挂在哪

**这是句子好不好听的关键。** 速度、幅度、犹豫，都要挂上去：

| 维度 | 挂什么 | 例 |
|---|---|---|
| **缓** | 缓慢 / 慢慢 / 缓缓 / 一点点 | 有些沮丧地**缓慢**摇头 |
| **急** | 猛 / 急 / 一下 / 连忙 | **突然**别开脸 |
| **轻** | 微微 / 轻轻 / 稍稍 | **微微**皱眉 |
| **重** | 重重 / 使劲 / 硬生生 | **硬生生**把话咽回去 |
| **犹豫** | 迟疑地 / 试探着 / 半途 | **试探着**抬了下眼 |

**注意**：形容词要挂对地方。「微微皱眉」是**轻**在动作上；
「有些沮丧地」是**状态**在总上。**两个不能混成一句乱堆**：

```
✗ 他微微有些沮丧地轻轻缓慢地摇了摇头   （形容词挤成一团）
✓ 他微微皱眉，抿了一下嘴，有些沮丧地缓慢摇头
```

**顺序也有讲究**：**轻/急挂小动作，缓/犹豫挂大动作。**
先快后慢＝犹豫，先慢后快＝决断。

### 合格的「总」词

**「语气副词 + 情绪词」**，把程度和犹豫带出来：

> 有些无奈的 ｜ 有点沮丧的 ｜ 含情脉脉的 ｜ 带着点笑意的 ｜
> 勉强乐了一下的 ｜ 忽然认真起来的 ｜ 像是松了口气的

**光秃秃的情绪名词不要**（「悲伤」「愤怒」）——那是标签。
**文学化的不要**（「情意像潮水漫上来」）——那是抒情，不是方向。

**「总」还兼当节拍器**：一场戏三到四拍，「总」每拍换（无奈 → 失落 → 硬撑），
「分」跟着换。**「总」不变而「分」在变 → 演成了持续状态。**

### 要改的是「没有人的句子」，不是情绪词

| ✗ 只有部位在某个状态（标本） | ✓ 总—分（有人在做一件事） |
|---|---|
| 眼泪**挂在**睫毛上 | **她有点绷不住了**，泪顺着眼角滑下去 |
| 视线**压**过去**不挪开** | **她有些急**，眼睛跟着他的脸转 |
| 微皱眉 ｜ 眼睑微垂 ｜ 眉心轻收 | **她有些发怔**，皱了皱眉，眼皮随即垂下去 |

**带「着」的持续状态——换掉**：
**挂 着 ｜ 盯 着 ｜ 悬 着 ｜ 绷 着 ｜ 压 着 ｜ 维持 ｜ 处于 ｜ 呈现 ｜ 笼 着 ｜ 揪 着**
判断法：**动词后面能不能加「着」还不觉得怪？** 能加 → 那是状态 → 换掉。
**自造词也不写**：绷起来 ｜ 打着转 ｜ 翻着个儿 ｜ 摩了两下。

### 三条写法

1. **每句都要有「总」**——总可以在前也可以在后，但**不能没有**。
   ✗ 眼泪挂在睫毛上 → ✓ 她有点撑不住了。吸了口气，睫毛轻颤，眼含泪花，嘴唇跟着抿了一下。
2. **动作顺着人走下来，不按部位排序**——第一个动作自然带出第二个。
   ✗ 眉→眼→嘴→肩 逐格填 → ✓ 她笑得有点勉强，眉心先收了一下；笑意还没收起，眼皮已经垂下去了
3. **不要竖线分隔，要连成句子**——「｜」是清单的形状，不是句子的形状。
   逗号连接同一动作内的小停顿，**句号断开不同动作**，一段 2–4 句。

### 写完五个自问

1. **有没有「总」？**（没有 → 补一个，放前放后都行）
2. **这个总是不是光秃秃的标签？**（是 → 补成「带着 A 又 B」，**不许用"A 地+动词"**）
3. **分有没有动作在走？**（没有 → 补身体证据）
4. **有没有轻重缓急？**（全是中速 → 给缓/急/犹豫挂上形容词）
5. **动作是顺着走下来的，还是并列堆的？**（并列 → 改接续）

**外加两条文体硬检查（见 [影视化微表情写法.md](references/影视化微表情写法.md) 自检表）**：

6. **有没有口语白描 / 抽象状态 / 部位黑话？**（有 → 一律不合格，重写）
7. **走完「反应—掩饰—泄露—回收」没有？**（只写反应就落 → 不合格）
8. **整段是不是全程用「影视化 / 分镜式的微表情描写」写的？**（不是 → 不合格，重写）

> **第 8 条是硬性规则的落点。** 上面七条是这一条的具体做法；
> 七条都对了、但文体不对（比如用了口语大白话、或写成总结腔），**照样不合格**。

完整对照（含「含情脉脉」「沮丧」多种写法对比）见 [写法-讲述不下指令.md](references/写法-讲述不下指令.md)。

## 一、五步推理（接到情境就走）

### 第 1 步｜读情境，定三件事

| 读什么 | 判断什么 |
|---|---|
| 谁对谁 | **关系**：亲疏、强弱、有无亏欠 |
| 发生了什么 | **触发**：是什么让情绪起来的 |
| 想得到什么 | **意图**：她此刻要争取／隐藏／试探／拒绝什么 |

**意图决定一切。** 同样流泪，想挽留和想告别是两套完全不同的写法。

### 第 2 步｜定情绪类型与弧线

四种基本类型，先归一个主类型：

| 类型 | 核心张力 | 常配的落点 |
|---|---|---|
| **委屈** | 想被理解 vs 说不出口 | 收住、咽回去 |
| **愤怒** | 想反击 vs 还有顾虑 | 压住或断然 |
| **掩饰** | 想藏 vs 藏不住 | 破绽留下 |
| **温情** | 想靠近 vs 有所保留 | 靠近半步或收住 |

**这一步同时定出每拍的「总」词。** 比如一场戏可以定成：
`有些过意不去 → 有些急了 → 嘴上还硬着 → 像是认了`。
**「总」词定了，下面十部位才会有方向。**

**⚠️ 定完类型，立刻去查 [情绪-肢体对照表.md](references/情绪-肢体对照表.md)**
——那里写明这个情绪的**主控部位、力量方向、反向部位**。
**主类型定错，后面全部白写。**

| 主类型 | 力量方向 | 主控部位 | **肩** ⚠️ |
|---|---|---|---|
| 委屈 | 往内收 | 唇 ｜ 呼吸 | **往里收、塌** |
| 愤怒 | 往外顶 | 下颌 ｜ 呼吸 | **往上提、挺** |
| 掩饰 | 藏一半 | 排他不对称 | 端着不动 |
| 温情 | 试探靠近 | 眼神路径 | 呼气时落下 |

**最容易写混的两对（记住）**：
**委屈 ⇄ 愤怒，肩是反的**；**掩饰 ⇄ 温情，眉眼顺序是反的**。

**★ 眉内侧可以「锁住」整段不动（v01 实测新增）**：
前面讲的「与眉反向」是**眉与眼此消彼长**。但还有一种情况：
**眉内侧从开镜就被拧住，一直不解，而眼在它下面开开闭闭。**

```
20s  眼睁开看人  →  眉内侧提得最高
32s  眼闭合      →  眉内侧仍在拧
50s  眼几乎闭上  →  眉内侧拧得最紧
```

**这不是反向，是「常驻标记」。**
**用在**：委屈 / 歉疚 / 忍痛 / 被压倒——**这类戏里眉内侧可以只在起拍写一次，
之后不再重复，它自己就在那儿**。不要每拍都写一遍"眉内侧提起"（废话）。
**但眼睛必须继续动**——眉不动、眼也不动，就成了呆若木鸡。

**★ 「被压倒的委屈」要先分「在争」还是「在受」（u09 + v01 实测）**：

```
在争（辩解、否认、解释）→ 嘴一直在动 → 泪停在下睑不往下走 → 最后整个身体往前塌（落·塌）  v01
在受（被训、不敢还口）  → 嘴一直闭着 → 泪能走完全程（下睑→一道→两道） → 身体不动，只流泪  u09
```

**判断法一句话**：**这一镜她是「在争」，还是「在受」。**
**在争 → 写嘴、写塌；在受 → 写泪、写不动。** 写反了就不像。

**⚠️ 而且不是每段都有「落」。** u09 全段停在流泪，**没有落拍**——
**"落在受"的戏里，可以不给落。** 不是每段都必须走完四拍。

**★ 写「崩溃」时必先分两极（u12 实测修正）**：

```
这个人是「忍着不说」还是「忍不住要说」？
  忍着不说（内敛）→ 嘴闭合/抿住，眼睛睁大、忘了眨，泪慢慢聚     （v06）
  忍不住说（外放）→ 先咬唇忍 → 松开+低头 → 抬头张嘴 → 眉内侧极高（u12）
```

**外放崩溃的完整动作链（照抄可用）**：
`咬住下唇（忍）→ 松开 + 低头（第一次松动）→ 抬头开口（决定说）→ 顶点`
**比直接喊出来高明得多。** 直接喊 = 没有过程。

**★ 复合情绪怎么写（u05 实测新增）**：
「又笑又想哭」「又气又怕」这类，**不是一半一半**：

```
① 拆成两个信号，分给两个部位（嘴给笑、眼给泪）
② 两个都写小——不是「一半笑一半哭」，是「两个小的同时」
③ 用排他指令隔开：嘴在笑时眼睛不参与；眼在湿时嘴照常
```

**实证**：u05「含泪的笑」那一格是 **嘴角上扬（笑）+ 眶内泪光 + 视线斜看侧前方**——
**两个都不大，各走各的**。写成「又哭又笑」（两个都大）就假了。

然后排**四拍弧线**：

```
起 → 推 → 顶 → 落
```

- **起**：情绪第一次露头（不一定大声，可能只是眼皮动了一下）
- **推**：往上加，身体的反应开始压不住
- **顶**：最高点。**不写结果，写到一半停住**——话说一半、手举一半
- **落**：给落点。**落有两种，先分清是哪种**（见下）

**★ 落有两种（u03 实测修正）**：

```
落·收住  → 口闭合、表情收、泪痕留          （情绪解决了）
落·压住  → 嘴张开停住、视线走开、泪痕留     （情绪只是压住，没解决）
```

**v06 是「收住」，u03 是「压住」。** 写之前先问：
**这个人的情绪是解决了，还是只是压下去了？**
**「压住」的落，嘴是张着的（要说没说），不是闭着的。**

**还有第三种落：塌（v01 实测）**——整个人**形体往下沉**，不是脸收干净：

```
落·塌  → 头低到抵住手/桌面、肩完全松开塌掉、脸不再给表情（v01 审讯段 56s）
```

**用在**：**被压倒**的戏（被审、被骂、被逼供到最后说不出话）。
**前两种落是"脸在收"，这一种是"整个身体先垮"。**

**顶之后必须有落。** 停在最高点＝没演完。

**每拍都要有「总」词**（见第零条）。四拍的「总」应该**不一样**——
一样就说明这段情绪没在走，只是一直摆着同一个状态。

### 第 3 步｜十个部位联动写满

**这是硬指标，不是参考。** 十个部位都要走一遍：

```
微表情 ｜ 微动作 ｜ 眼神 ｜ 眼皮 ｜ 嘴唇
呼吸 ｜ 肩颈 ｜ 手指 ｜ 头部 ｜ 身体重心
```

**⚠️ 十处不是等重的。眼神与眼皮是主引擎**，变化最快、信息量最大，
其余部位**跟它们走，不要各写各的**。权重只是「变化幅度」的依据，**不是可以不动**：

| 部位 | 权重 | 部位 | 权重 |
|---|---|---|---|
| **眼神** | ★ 主 | 嘴唇 | 中 |
| **眼皮** | ★ 主 | 呼吸 | 中 |
| 微表情 | 中 | 手指 | 中 |
| 微动作 | 中 | 头部 | 中 |
| — | — | 肩颈 / 身体重心 | 低 |

**三个要求：**

- **持续** —— 每个部位至少两次变化，不能开镜给一次就定住。
  任意取两个时间点，十处里不该有超过三处完全一样。
- **自然** —— 不是十处一起动。**错峰**：一处先起，另一处跟上。
  核心部位变化最大，其余小幅跟随。
- **联动** —— 部位之间是**接续**关系，不是并列堆砌。四条常用链路（左为总，右为分）：

  ```
  她注意到什么  → 视线跟过去 → 眼皮抬起 → 眉心收紧
  她在压住什么  → 呼吸变浅 → 肩抬起来 → 声线变紧
  她想做什么    → 手指收拢 → 手臂抬起 → 到半路收回
  她想转开      → 头部偏过去 → 颈跟着转 → 上身让开
  ```

**程度按情境定。** 轻微的情绪就是十处都微幅变，不是十处大幅变。

### ★ 先查这张表：什么情绪，哪个部位往哪动

**十部位清单只回答「哪些部位要写」。** 它不回答「**这个情绪下，那一处该往哪个方向动**」——
而方向写反了，读出来就是另一个人。

**委屈和愤怒，肩是反的**（委屈往里收、愤怒往上提）；
**掩饰和温情，眉眼顺序是反的**（掩饰笑先起、温情眼先走）。

| 情绪 | 力量方向 | 主控部位 | **肩** ⚠️ | 手指 | 落点 |
|---|---|---|---|---|---|
| **委屈** | 往内收 | 唇 ｜ 呼吸 | **往里收、塌** | 收拢、攥紧 | 咽回去 |
| **愤怒** | 往外顶 | 下颌 ｜ 呼吸 | **往上提、挺** | 握拳、压桌 | 压住／断然 |
| **掩饰** | 藏一半 | 排他不对称 ｜ 眼与皮错位 | 端着不动 | 找无意义动作做 | **破绽留下** |
| **温情** | 试探靠近 | 眼神路径 ｜ 嘴上半 | 呼气时落下 | 伸一半收回 | 靠近半步／收住 |

**反向部位要往相反方向走**——不要顺手跟主控一起写。
**「掩饰不能写成功」**：写成功＝平静，就没戏了；**破绽必须留下**。

> **完整对照表（含四类签名句 + 横向速查 + 六种其余情绪）见
> [情绪-肢体对照表.md](references/情绪-肢体对照表.md)。**
> **写情绪之前先对一眼这张表——这是「动得对」和「动得不对」的分界。**

**⚠️ 但真实的脸不是链条，是网。** 上面四条链路只是**常见模式**，不是必须按顺序走。
情绪复杂时，**几处同时活着、互相牵动**：眼睛在追，手在收；呼吸在乱，下巴在抬。
**顺着一条线走完再走另一条，就演成了程序。**
写完读一遍——**这张脸是「一条线」还是「活着的」**，这是判断标准。

**一处动作写出来，别的好处是脸会活；坏处是——如果那一处根本不在，AI 会为了让观众看见它，把整张脸转过来。**
这是 AIGC 特有的翻车，传统拍摄没有。所以：**写你确认在的那一处；那一处不在，就写它牵连到的别处。**
**不要为了「写全」把脸转过来。**

### 第 3.5 步｜★ 眼神与眼皮——最重的一处，单独写

**眼神非常重要**，人的眼神是灵活的，也是会眨眼的。
人在情绪很复杂的时候，需要很灵动的搭配。**眼神，眼皮子，非常重要。**

**这两处不是十部位里普通的两条，是「灵动」的主引擎。** 写完要单独过一遍：

**① 眼神要有「路」，不是方向**

```
起点 → 移动 → 落点 → 返回
```
- ✗ 她看着他 → ✓ 她眼睛从他脸上滑到嘴唇，又绕回眼睛
- **落点必须是看得见的东西**（眼睛／手／桌面／门口），不能是「远方」「内心」
- **返回时机说话**：立刻回＝在意；拖一会儿才回＝心虚；不回＝决心已定

**② 眼皮要有「半途折返」**

```
眼皮往下一沉 → 沉到一半又抬起来 → 再沉下去
```
**一次到位＝交代；两次＝挣扎。** 情绪常在一个**一半的位置**，不在全开或全闭。

**③ 眨眼必须写**

- 快＝紧张慌乱 ｜ 慢＝累、麻木、认了 ｜ **忘了眨＝人不在，或不敢动**（最高级）
- 不写次数（那是我禁的数值化），**只写时机和频率**

**④ 眼与皮的四种配法**（后两种最值钱）

| 配法 | 读出的意思 |
|---|---|
| 眼到、皮跟上 | 专注、想要 |
| 眼到、皮压住 | **克制**：想看看，又不敢看 |
| 皮抬、眼不动 | 走神、听不进 |
| 眼走、皮慢半拍 | 舍不得、告别 |

**⑤ 与眉反向**：眼睁大↔眉抬起，眼微垂↔眉松开。**此消彼长，不同向用力。**

**⚠️ 但眉内侧可以「锁住」整段不动（v01 实测）**：
有些戏里眉内侧从开镜就拧着，**一直不解，而眼在它下面开开闭闭**。
**这不是反向，是常驻标记**——委屈 / 歉疚 / 忍痛 / 被压倒的戏，眉内侧**写一次就够**，
之后不必每拍重复（重复＝废话）；**但眼睛必须继续动**，两个都不动就是呆若木鸡。

**⑥ 眨眼里夹一层意思**：`她眨了一下眼睛，再睁开时眼神已经变了。`

**⑦ ★ 泪能走多远，取决于「这个人开不开口」（v01 实测新增）**

前面几条讲泪**分几段**。这里补**段走得快慢由什么决定**：

```
一直在说话  → 泪停在下睑／眶内，不往下走      （说一句、咽一口，泪就断）v01
一句话不说  → 泪能走到「滑到腮边、挂满」      （没有嘴的动作打断它）v06 · u03
```

**实证**：v01 里她一直在说话，泪**只走到第二条相**（下睑水光 → 泪痕到下颊）就停了；
u03 里她一句话不说，泪却走完**四条相**（水光 → 一道 → 两道 → 留下）。
**跟戏的长短无关，看的是她有没有在说话。**

**写之前先问**：这一段她是**在辩解/控诉**（泪停住），还是**说不出话**（泪能走远）。
**她一直在说话，就不要写成泪流满面。**

> **完整展开（含三段成片的逐帧实证、可直接改用的句子、专项检查表）
> 见 [眼神与眼皮.md](references/眼神与眼皮.md)。**
> **这一份不是「按需才翻」，写复杂情绪就该看。**

### 第 4 步｜过六张禁用卡

**卡一：结果状态 → 改过程**

**注意右列的形状**：给的是**过程链**（谁在怎么受力），不是把左列的形容词换个说法。

| ✗ 结果状态 | ✓ 改成过程 |
|---|---|
| 眼泪挂在睫毛上 | **她有点绷不住了**，吸着气，泪顺着眼角滑到腮边 |
| 面色铁青 | **他在压着**，下颌收住，鼻翼随吸气撑开，眼睑压下来又抬起 |
| 指节泛白 | **她有些失控**，手把杯子推远，指头收拢又松开 |

**卡二：裸状态 → 加总、加方向**

愣住／呆住／僵住／直盯／死死／紧紧／目光注视／眼睛睁得很大 —— 全部改写：

| ✗ 裸状态 | ✓ 总＋分 |
|---|---|
| 直盯 | **她有些急**，眼睛跟着他的脸转 |
| 眼睛睁得很大 | **她像是没想到**，眼皮挣开往上翻，眼白露出来 |
| 死死掐住 | **她有些失控**，指头收进掌心 |
| 目光注视 | **她看住了他**，视线落在他脸上，没走 |

**卡三：抽象判断 → 拆成肌肉与方向**

**「放平」「绷住」「松了」「平静下来」这类词描述的是「整张脸的结果」，不是动作。**
**模型拿到它不知道动哪里、往哪儿动。必须拆。**

| ✗ 抽象判断 | ✓ 拆成具体动作 |
|---|---|
| 整张脸放平 | 眉心展开，上眼皮落下来，嘴角跟着松 |
| 脸绷住 | 眉心往中间收，上眼皮撑开，嘴角往两边拉 |
| 表情松了 | 眉尾落下来，眼皮不再撑着，下颌往下沉 |
| 神情平静 | 眉心展开，呼吸匀下来，眼皮垂到自然的位置 |

**判断法：这个短语能不能落到「哪块肌肉、往哪个方向」？**
不能 → 你在写观察结论，不是在写动作。

> **注意区别**：`她像是认了` 这样的「总」是**允许的**（那是情绪方向，见第零条）；
> `整张脸放平` 是**不允许的**（那是脸的结果判断，没有方向也没有肌肉）。

**卡四：自造词与假动作**

绷起来／打着转／翻着个儿／摩了两下 —— 不写。
「停住／停／悬在／悬空／没放下」—— 不写（**但「有意图的撤回」要写**，见第四节）。

**卡五：数值化幅度 → 改部位级排他**

| ✗ 数值化 | ✓ 部位级排他 |
|---|---|
| 眉心聚拢 15 度 | **她有些不悦**，皱了皱眉 |
| 双肩内收 2-3 厘米 | **她在忍**，肩往回收，胸口跟着塌下去 |
| 振幅不足一毫米的颤抖 | **她在硬撑**，下唇轻颤 |
| 眼睑抬升耗时 1.5 秒 | **她像是没反应过来**，眼皮抬起又垂下 |
| 0.2 秒的卡顿 | **她犹豫了一下**，先快后慢，睁开前有点迟滞 |

**诊断是对的**（「微微」「轻轻」确实容易被模型淡化），**但药方不成立**：
模型读不出「半度」「毫米」，等于往提示词里塞噪声。
**正确解法是不说方向幅度，说「哪一处动、哪一处不动」。**

**卡六：写了大面积一起动 → AI 把脸转过来**

**这是 AIGC 特有的翻车，传统拍摄没有这个问题。**

| ✗ 大面积一起动（AI 会转脸） | ✓ 只写一处，其余给牵连 |
|---|---|
| 「两侧嘴角一起压下去」 | **只写一侧嘴角往下压**，另一侧不动 |
| 「整张脸放松下来」 | **写眉和嘴角松下来**，别写「整张脸」 |
| 「她眼睛红了」 | **写肩往上提了一下，手指在袖口收拢，呼吸变浅** |
| 「她眼神变了」 | **写手指收拢，压住桌面** |

**病根**：AI 分不清「描述现状」和「要求它动」。
**你写「半边脸的嘴角压下去」，它可能把脸转过来好让嘴角正对观众。**

**判断法：这个动作，写出来是不是「一整片一起动」？**
是 → **改成一处，或写它牵连到的别处**（肩、呼吸、手指）。
**别为了「写全」把脸转过来。**

**特别提醒：手部、背部这类地方，就不要写眼睛。** 写眼睛 AI 就会去拍眼睛。

> **更多反例（十类，含错在哪 + 怎么改）见 [反例集.md](references/反例集.md)。
> 写完对一遍，尤其是「抽象判断」「程序感」「眼神眼皮」三节。**
>
> **十部位都写了、读着还是不对劲，查 [补强-肌肉与中断.md](references/补强-肌肉与中断.md)。**

### 第 5 步｜四种感觉，逐项过一遍

导演要的不是「写完了」，是**有这四种感觉**。每写完一场戏，对一次：

| 感觉 | 靠什么实现 | 没做到长什么样 | 查证处 |
|---|---|---|---|
| **电影感** | 情绪写完整过程，不给状态 ｜ 表里反差 ｜ 微表情够细够小 ｜ 有轻重缓急 | 只给一个状态让画面停着；表情大到像话剧；整段一个速度 | 基准档案（9 段实测） |
| **灵动感** | 十部位错峰联动 ｜ 动作连着走 ｜ 有轻重缓急 ｜ **眼神有路、眼皮折返** | 一处动或十处同时动；全中速；眼神只有一个方向 | 反例集·第七节 |
| **真实感** | 排他指令 ｜ 撤回有受力原因 ｜ 表里反差 ｜ 表情不完整不对称 ｜ **写够、不超范围** | 表情过度对称、过度完整；该动的没写（呆若木鸡）或写过了头 | 补强文件 |
| **丰富感** | 每处至少两次变化 ｜ 四拍的总各不相同 ｜ 泪/笑/停分阶段 | 开镜一个状态到底 | v06 锚点档案 |

**这四项不达标就是没写完，不是「差不多了」。**
**每一项都在「查什么」那一列指向了实物依据——不达标时去查，别硬猜。**

> **「电影感」在本模块只指情绪那一半**：过程演得完不完整、幅度对不对、有没有轻重缓急。
> **画面质感、镜头运动、布光调色——不归本模块，本模块一个字不写。**

## 二、十个部位——写的时候怎么落到句子里

**注意：下表不是让你按格填。** 十部位是**检查清单**，不是**写作顺序**。
写的时候从「她在做什么」出发，动作自然带出部位；写完再拿这张表核对有没有漏。

| 部位 | 可以直接用的说法 | 放进句子里的样子（总＋分） |
|---|---|---|
| 眉 | 微皱眉 ｜ 眉心微收 ｜ 眉梢轻抬 | 她有些为难，微皱眉，眉心又松开 |
| 眼 | 眼睛微睁 ｜ 眼睛稍收窄 ｜ 眼睑微垂 | 她有些意外，眼睛微睁 |
| **眼皮** | 眼皮抬起 ｜ 睫毛轻颤 ｜ **半途折返** | **她有些犹豫**，眼皮沉下去，沉到一半又抬起来 |
| 眼神 | 视线跟着他的脸 ｜ 目光滑开 | 她有些泄气，目光从他脸上滑开，落到桌面 |
| 唇 | 嘴角微撇 ｜ 嘴唇轻抿 ｜ 嘴微张 | 她有些发慌，嘴微张，话又咽了回去 |
| 鼻／呼吸 | 轻轻吸气 ｜ 呼出去时肩跟着落 | 她像是松了口气，轻轻吸了口气，肩膀跟着落下去 |
| 头／颈 | 下巴微抬 ｜ 头轻偏 ｜ 头微低 | 她有些不好意思，头轻偏，把脸让开一点 |
| 肩 | 肩往里收 ｜ 肩落下去 | 她在忍，肩往里收，胸口跟着塌下去 |
| 手指 | 手指收拢 ｜ 指尖松开 | 她有些不安，手指在杯壁上收拢 |
| 重心 | 上身前迎 ｜ 上身收回 | 她有些急，上身前迎了半分，又收回来 |

**注意右列的词长**：**微／轻／稍 ＋ 具体部位**（微皱眉・眼睑微垂・睫毛轻颤・下巴微抬）。
这是导演认可的口径（原话举例「微微皱眉，眉心微收」）。
**不是自造，不是绕圈描述幅度。**

**同义换算表（导演逐条给的口径，照换就行）**：

| ✗ 不写 | ✓ 换成 |
|---|---|
| 眼睛亮起来 | **眼睛微微一睁** |
| 眉心一点点往里聚 | **微皱眉** |
| 眼皮往下压合了半格 | **眼睑微垂** |
| 嘴角往一边撇 | **嘴角微撇** |
| 抬眼又压回 | **眼皮抬起又垂下** |
| 下巴抱紧 | **下巴微收** |

**注意「眼睛亮起来」这一条**：它是**结果，不是动作**——
「亮」是观众看完之后下的判断，模型拿到它不知道动哪儿。
**眼睛的「亮」是睁大挣出来的**，所以写**眼睛微微一睁**。

**禁止数值化**：不写「15 度」「2-3 厘米」「1.5 秒」。
改**部位级排他**：不说「只动 15 度」，说「**只动这一侧嘴角，另一边没动**」。

## 三、两条进阶手法

### 肌肉调度 —— 给表情排先后

**写不出过程，常常是因为不知道先动哪儿。** 把一张脸拆成肌肉的先后手：

| 次序 | 肌肉 | 写什么 |
|---|---|---|
| 第一 | 皱眉肌 | 眉心收、挤出竖纹 |
| 第二 | 口轮匝肌 | 嘴唇失控——抖动、张开、抿住 |
| 第三 | 额肌 | 眉心展开、上眼皮落下来、嘴角松 |

**不要三块同时动**（同时动＝标准面具）。**收尾必须额肌先松**，脸才收得住；
反过来写（先松脸再动嘴）会假。

> 例：「眉心聚拢，挤出两道浅浅竖纹」→「下唇失控地抖」→「眉心缓缓展开，上眼皮跟着落下来，嘴角松了」

### 排他指令 —— 该不动的地方不动

不对称要写成两句话：「**只动这一侧**」＋「**另一侧禁止参与**」。

> 只动一侧嘴角，另一边不动 ｜ 眼部不参与（笑意不扩散到眼底）

**写「苦笑」不能只写嘴角，要写清它没能抵达哪里**——没扩散到其他区域、全然没抵达眼底。

**人类情绪从不纯粹、也从不完整。** AI 感的一大来源就是表情过度对称、过度完成。
**该不动的地方不动，比多动一处更像人。**

### 第三条 · 施压方怎么写（v01 + u09 两段独立印证）

**戏里常有一个人逼着另一个人。逼人的那一方，不能"一路凶到底"。**
两段成片各自用了**同一个手法**：

```
v01 审讯   硬（逼视）→ 硬（二十六处刺伤）→ 硬（身体前压）
           → 软一下：「没事的，你当时只是害怕」→ 立刻又硬回去（你告诉我我才能帮你）
u09 田野   质问（眉心微收、张嘴说）→ 闭嘴等着（沉默施压）
           → 责备（眉压低、下颌前推、嘴张开说话）→ 转调：「爱情固然美好，但金钱是绝对必要的」
```

**规律**：**凶过之后，要软一下，说一句"我是为你好"式的话，然后戏才压得更实。**
那一软**不是真的收**，是**为了逼出对方的反应**。

**另一条**：**眉的方向换一下，情绪就换一种**——
**眉心微收＝质问**；**整条眉压低＝责备**。同一场戏里可以换。

**注意**：施压方**也有情绪弧线**，不是背景板。
**只写承受方、把施压方写成一堵墙，戏是死的。**

## 四、撤回 ≠ 静止（分清）

| | 写不写 | 为什么 |
|---|---|---|
| **无意义的静止** | ❌ 不写 | 到位后停着不动＝画面死了 |
| **有意图的撤回** | ✅ **要写** | 动作起来了又收住，这个「收」本身就是戏 |

写法：**先给起势，再写它在半路被压回去**：

- **她还想说**，话到嘴边又咽了回去
- **她有些舍不得**，似要张臂去抱，又收住
- **她有点怀疑**，摇头起了一半，慢下来，像忽然记起什么
- **她忍着**，眼眶泛红，泪在眼睑边缘积住
- **她犹豫了**，手抬起来，又落回膝上

**关键**：写清**是什么力量把它压回去**（忍、记起某事、对方一个眼神）。
**没有来由的中断＝另一个静态。**

**另一类对冲**：两种相反的情绪紧接出现，要标出时序——
> **她有点不甘心**，眼底的悲伤还没散，眼神紧接在之后变锐利

用「紧接在……之后」「同一瞬间」**标注时序，不用秒数**。

## 五、句子句法

> **这是「影视化 / 分镜式的微表情描写」在句子层面的落点。**
> 它就是把那条硬规则拆成一条条能执行的句法。**全部是硬要求。**

0. **总在前，分在后；也可以分在前、总在后**——但两种都要有。**这是最上面的一条。**
   总→分：**他有些无奈又好笑**，轻轻摇了摇头，嘴角跟着扯了一下。／ 分→总：微微皱眉，抿了一下嘴，**那点无奈慢慢收了回去**。
   **⚠️ 「总」写成「带着 A 又 B」，不许写成「A 地+动词」。**
1. **一句里放两个相反的东西**——「嘴角还留着礼貌弧度」＋「眼神已经越过她去找未婚夫」。
2. **写「因为什么在受力」**——「肩保留被妹妹牵住的受力状态」，不写「肩膀侧了一点」。
3. **写到一半停住、不写结果**——「嘴唇因困惑微分却没说话」，**不许写「说完……」**。
4. **形容词要挂对地方，还要有轻重缓急**——缓／急／轻／重／犹豫各有其词，
   **轻急挂小动作，缓犹豫挂大动作**；不要挤成一团。
   ✗ 他轻轻又缓慢地摇了摇头 → ✓ 他微微皱眉，抿了一下嘴，那点无奈慢慢收了回去
5. **动词连走、句号一断**——「扫 → 送回 → 收紧 → 闭住」。
   **逗号不许一路堆**：一镜段落里逗号连堆 6 个以上＝被切成清单，读起来程序化。
   并列动作用**句号断开**，每段 2–4 句。
6. **不用破折号当拐杖**——并列动作断成句号，不靠「——」串起来。
   ✗ 她张了张嘴——话涌到嘴边 → ✓ 她嘴微张，话涌到嘴边，喉头动了一下
7. **一段里主语只出现一次**——后面跟着走，不重复「她……她……」。
8. **一句一个部位**——不在一句里堆十个部位；换人＝换行。
9. **眼神必须写「路」**——起点 → 中间落点 → 回到对方脸上。只写方向＝不合格。
10. **「没做成的」比「放」写得多**——本来要扬起又抿住／准备侧开半步又停，
    收回的那一下就是戏。

## 六、输出格式

```
情绪类型：<主类型>｜弧线：起 → 推 → 顶 → 落
每拍的总：<起> → <推> → <顶> → <落>

【起】  <总词>。<动作或状态>，<十部位联动，写出过程>
【推】  ...
【顶】  ...
【落】  ...
```

**先写「每拍的总」，再写分。** 这一行是自查——四个总词如果差不多，说明这段没在走。
**「总」在句首句尾都行**：定调用在句首，追认/收落用在句尾。

**轻重缓急也要拍到**：一场戏里至少有一处是缓的、一处是急的，
**全中速就是没节奏**。

**只写情绪。** 除了这几行，**不加任何别的字段**——不加景别、不加画面说明、不加节奏说明。

## 七、示例

**情境**：她拿着杯子坐在餐桌这头，对面是刚说完「我们不合适」的人。她想反驳，但没开口。

```
情绪类型：压怒 → 崩塌 → 硬撑｜弧线：起 → 推 → 顶 → 落
每拍的总：还有些过意不去 → 有些急了 → 嘴上还硬着、人已经撑不住了 → 像是认了

【起】她还有些过意不去，勉强扯了下嘴角。
      只扯起半边，另一边没动，眼睛也没跟着笑。手把杯子慢慢往桌里推。
【推】她有些急了，眉心先收，眼睛跟着收窄，声音一下提起来。
      手指在杯壁上收拢，视线跟着他的脸不肯放。吸气时鼻翼撑开，
      肩往里收，胸口跟着塌下去。
【顶】她嘴上还硬着，人已经撑不住了。杯子被推得撞上桌沿。
      她嘴微张，话涌到嘴边，喉头动了一下，又硬生生咽了回去。
      下眼睑往上收，眼皮抬起又垂下，眨眼比刚才快。
【落】像是认了，她肩缓缓落下去，眉心一点点展开，上眼皮跟着落下，嘴角也松了。
      目光从他脸上滑开，落到桌面，嘴唇抿住。手覆上杯口按住。
      眼含泪花，没有落下来。
```

**为什么合格**：
- **每拍先给总**——「还有些过意不去」「有些急了」「嘴上还硬着，人已经撑不住了」「像是认了」，
  方向先立住，身体再跟上
- **有轻重缓急**——起拍「慢慢往桌里推」（缓）→ 推拍「一下提起来」（急）
  → 顶拍「硬生生咽回去」（重）→ 落拍「缓缓落下去、一点点展开」（缓）。
  **缓→急→重→缓，这就是节奏。**
- **分跟着走**——嘴微张→咽回去→眼皮垂下→肩落→目光滑开，一条线
- **顶拍是撤回**，且给出受力原因（话涌上来 / 自己压下去）
- **落拍按额肌先松**收脸，眼含泪花没落下来（这是「压住」的实证，不是「哭了」）
- [ ] **没有裸状态**（无挂着／盯着／悬着）、没有计时器、没有数值
- [ ] **没有破折号当拐杖**（并列动作用句号断开，不用「——」串）
- 逗号连同一动作内的小停顿，句号断不同动作

## 七之二、示例二｜崩溃戏（按 v06 锚点档案的实测写）

**情境**：她刚听完一句判决式的话，站在原地说不出话。

```
情绪类型：崩塌｜弧线：起 → 推 → 顶 → 落
每拍的总：先是没反应过来 → 有些受不住 → 整个人撑不住了 → 像是认了

【起】她先是没反应过来，眼睑微垂，嘴唇动了动，没出声。
【推】她有些受不住，轻轻吸了口气，鼻翼一下一下地撑。眼睛越睁越大，
      眨眼比刚才少，像是怕一闭眼事情就定了。肩往上抬，手指收进掌心。
【顶】她整个人撑不住了。眼睛一直睁着，忘了眨。眼里盛着泪，
      她仰起头想压回去。压不住，泪顺着眼角滑到腮边。
      嘴微张，喉咙动了一下，没发出声。
【落】像是认了，肩缓缓落下来，眉心展开，眼睑微垂，
      嘴角松了。泪痕还在，下巴还在抖，眼睛闭上了。
```

**实证依据（不是我想的）**：v06 顶点那一段**全程睁大、眨眼极少**——
这是「不敢眨」而不是「睁得很大」。**眼睛一直睁着 ＝ 人不在，或不敢动**（见第 3.5 步③）。
落拍**泪痕还在但表情已经收住**，也不是我编的。

> 完整逐帧读数（每一拍 × 唇/眼/泪/眉/头肩）见
> `情绪图谱\v06崩溃哭戏\锚点档案.md`。**写哭戏之前对一遍。**

## 七之三、四类情绪的起手式（可直接改用）

**起拍第一句最难写。** 下面每种给一句，按情境改词即可：

| 类型 | 起拍总词 | 起拍句 |
|---|---|---|
| **委屈** | 她还有些过意不去 | 她还有些过意不去，嘴角微微往下收，眼睛没敢抬 |
| **愤怒** | 她先是没吭声 | 她先是没吭声，下颌收住，呼吸变浅 |
| **掩饰** | 她像是没事 | 她像是没事，笑先起来，眼睛慢了半拍才跟上 |
| **温情** | 她有些舍不得 | 她有些舍不得，视线在他脸上停了一下，又滑开 |

**注意**：这四句都带**表里反差**（笑容先起、眼睛慢半拍＝掩饰；视线停一下又滑开＝不敢久看）。
**没有反差的第一句，基本就是摆姿势。**
**四句都用「微／轻／稍 ＋ 部位」这一档的词**（微微往下收・慢了半拍・停了一下），
**不用口语大白话，不用自造词。**

## 八、边界

- 本模块**只做情绪本身**。项目上下文、人物身份、剧集信息由导演技能另行提供。
- 剧本结构改写、剧情增删**不归本模块**。**改变剧情走向才需要问导演**，写法判断不问。
- **不编造剧情事实**。人物关系、前后因果以原文为准；原文没给的，按最合理的一种演法处理并在交付里标明是判断。
