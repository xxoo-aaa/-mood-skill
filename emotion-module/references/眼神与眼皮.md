# 眼神与眼皮 —— 情绪最重的一处

> **★ 文体硬规则（不可协商）**：**必须要使用影视化 / 分镜式的微表情描写。**
> 本文件第四节「直接拿去用的写法」已按这条规则写好，可直用。

**眼神非常重要**——人的眼神是灵活的，也是会眨眼的。
人在情绪很复杂的时候，需要很灵动的搭配。**眼神，眼皮子，非常重要。**

**为什么这两处单独成篇：** 脸上能演的东西里，眼神和眼皮是**变化最快、信息量最大**的。
嘴在说话时被占用，眉幅度小，头太大会变成晃；**只有眼神和眼皮能在半秒里换三次意思**。
情绪要「灵动」，主要就靠这两处活着。

---

## 一、眼神：要写「走的路」，不是「看的方向」

**「看着」「盯着」「注视」都是方向，方向没有戏。眼神要有路径。**

### 四段路——每一段都要写

```
起点（现在看哪儿）→ 移动（怎么过去、快还是慢）→ 落点（停在哪）→ 返回（什么时候回来）
```

**最常见的错：只写起点和落点，不写移动和返回。**

| ✗ 只有方向 | ✓ 有路 |
|---|---|
| 她看着他 | 她眼睛从他脸上滑到嘴唇，又绕回眼睛 |
| 她避开视线 | 她眼睛往下一沉落到桌面，隔了一会儿才慢慢抬回来 |
| 她直直看人 | 她视线跟着他转，他偏头她也偏头 |

### 落点要能看见

落点是**具体的东西**：他的眼睛、他的嘴唇、他动的手、桌面、门口、远处。
**「远方」「内心」「回忆」不是落点**——镜头里拍不到。

### 返回时机会说话

**同一段注视，返回的早晚决定意思完全不一样：**

| 什么时候回 | 读出来的意思 |
|---|---|
| **立刻回** | 在意、怕被发现、想确认 |
| **拖一会儿才回** | 心虚、在算计、下决心 |
| **不回** | 放弃了、决心已定、不想再谈 |

**这是免费的戏**：不要只写「移开视线」，要写**多久之后回来、回来时变没变**。

### 素材实证（成片逐帧读出来的）

- **v01 审讯**（恐惧回避型）：她是**低头 → 抬眼看人 → 眼一接触就沉回去**的循环，
  **一次接一次地重复**。**抬眼只到一半就落回来**——这是「不敢对视」，不是「不看人」。
  她始终在偷看，只是不敢停。
- **v03 分手**：女方的视线是**跟随的**——他走到哪儿她跟到哪儿，
  但**不落到他脸上**，落在他的肩、手、背后。**回避型的人用「不落在脸上」代替「不看」。**
- **v06 崩溃**：**顶点全部是对视**——眼泪流着也没有移开。
  **落拍才第一次目光滑开**。→ **情绪最浓的时候反而看得最死。**

### 双人：视线要有交互

**A 看 B → B 收到 → B 反应 → A 看见** —— 这是四步，不是两步。
**只有 A 看、B 没反应，戏就断了。**

- 一方移开，另一方的视线要**跟过去一点**再收回来（追）
- 一方看回来，先看到的人**要接住**（不能无动于衷）
- 两人同时移开 → **避开冲突的时刻**，这时候通常配沉默

## 二、眼皮：情绪最灵敏的一处，也是最容易被漏写的

**眼皮是这个模块里最被低估的部位。** 它的动作幅度极小，但**每一次抬起落下都带意思**。

### 眼皮的五种状态（每种不是一个动作）

| 状态 | 怎么发生 | 什么时候用 |
|---|---|---|
| **抬起** | 从上睑开始向上开 | 惊讶、想看、想要 |
| **垂下** | 上睑往下落，不一定合上 | 失望、放弃、掩饰、认输 |
| **微颤** | 上睑小幅抖动、频率高 | 忍住、快撑不住了 |
| **半合** | 垂到一半就停在那儿，只有上睑还在小幅抖 | 打量、轻视、慵懒 |
| **眨得快／慢** | 频率变化本身就是情绪 | 快＝紧张慌乱；慢＝累、麻木、认了 |

**「半合」这类中间状态最容易漏**——很多时候情绪就在**一半的位置**，不在完全睁开或完全闭上。

### 眼皮变化的完整写法（不是一句「眼皮垂下」）

```
眼皮往下一沉 → 沉到一半又被自己抬回去 → 再沉下去（这次到底）
```

**为什么这样写**：**「沉到一半又抬起」才是人。** 一次到位＝交代，两次＝挣扎。

### 眨眼必须写

**眨眼是免费的真实感。** 现在 9 段成片里**每一段都有自然眨眼**，
而且**情绪越紧张眨得越快**。

- **不要设次数配额**（「眨三次」）——那是数值化
- **写时机和频率**：`她说完这句，眨了一下，眨眼比刚才快`
- **眨眼跟情绪走**：憋泪时眨得小心；**人不在状态时忘了眨**（忘眨本身就是戏）
- **「忘了眨」是高级写法**：`她一直没眨眼，直到泪要溢出来才慌着眨了一下`

### 素材实证

- **v06 崩溃**：眼睑**每一次都不一样**——
  微垂 → 睁大 → 垂 → 睁大 → 垂。**是来回的，不是单向的。**
  **顶点全程睁大不停**——情绪到顶时眼皮反而**不动了**（因为不能动，一动泪就掉）。
  这是「忍」的实证：**不是眨眼快，是快得不敢眨。**
- **v01 审讯**：**眨眼明显比日常快**，尤其在对方追问时。
  低头段眨眼频率高 → 抬眼时**一次眨得特别慢**（在看人之前先缓一下）。
- **v03 分手**：**眨眼极慢**，有几次像是**忍住了**。
  **慢眨眼＝这个人已经累了、认了。**

## 三、眼神与眼皮怎么配（这才是「灵动」的核）

**这两处不能各写各的，它们是一套。** 常见的四组配法：

| 配法 | 写法 | 读出来的意思 |
|---|---|---|
| **眼到、皮跟上** | 视线过去，眼皮跟着抬 → 情绪上顶 | 专注、想要 |
| **眼到、皮压住** | 视线过去，眼皮反往下压 → 两个相反的东西 | **克制**：想看看，又不敢看 |
| **皮抬、眼不动** | 眼皮抬起来了，眼珠没转 | 走神、听不进、人在别处 |
| **眼走、皮慢半拍** | 视线先移开，眼皮随后才落 | 舍不得、告别 |

**第二组和第四组最值钱**——
**「眼和皮走向相反」或「差半拍」就是「人」和「模型」的分界线。**

### 与眉的反向规律（v06 实证）

```
眼 睁大 ↔ 眉抬起
眼 微垂 ↔ 眉松开
```

**此消彼长，不是同向用力。** 做成同向（眼大眉紧）＝标准面具。

### 眨眼里加一层意思

**眨眼的瞬间是换情绪的好时机。** 人常常是**闭一下眼，再睁开就变了**：

```
她眨了一下眼睛，再睁开时眼神已经变了，刚才那点软收干净了。
```

比「她态度变了」有力得多，而且模型能演。

## 四、直接拿去用的写法

### 眼神（挑一条改）

```
她视线从他脸上滑开，落到桌面上，隔了一会儿才慢慢抬回来，比刚才低半寸。
她眼睛跟着他的脸转，他偏头她也偏头，始终不肯先落回别处。
她抬眼只抬到一半就沉回来，眼睛还留在他身上。
她一直看着他的眼睛，眨得比刚才慢。
她没有移开视线，眼里含着泪光又憋回去。
```

### 眼皮（挑一条改）

```
她眼皮往下一沉，沉到一半又抬起来，再看回他时眼神已经稳了。
她眨了一下眼睛，再睁开的时候那点笑意没了。
她一直没眨眼，直到泪快要溢出来才慌着眨了一下。
她眼皮往下压，眼睛却从下眼睑上面看着人。
她说这句的时候眨得很快。
她眼皮慢慢合上又慢慢睁开，像是缓了一口气。
```

## 五、写完检查（眼神眼皮专表）

```
□ 眼神有没有路径（起点→移动→落点→返回），还是只有方向？
□ 落点是不是具体可见的东西（不是「远方」「内心」）？
□ 移开之后，有没有写什么时候回来、回来时变没变？
□ 双人戏里，视线有没有交互（A看→B收到→B反应→A看见）？
□ 眼皮有没有写「半途折返」（沉到一半又抬起）？
□ 有没有写眨眼？频率跟情绪走吗？
□ 「忘了眨」这种高级情形，该用的时候用了吗？
□ 眼神与眼皮的走向，是顺向还是反向？差异拍出来了吗？
```
