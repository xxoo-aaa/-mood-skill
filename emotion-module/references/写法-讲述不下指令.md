# 写法：总—分结构，讲述而不是下指令

> **★ 文体硬规则（不可协商）**：**必须要使用影视化 / 分镜式的微表情描写。**
> 本文件是这条规则的**句法层拆解**，唯一文体标尺见
> [影视化微表情写法.md](影视化微表情写法.md)（凡冲突，以那一份为准）。

**这是本模块的第一课，也是最难的一课。** 病根是**生硬**——
「挂着、盯着什么什么」这类写法，人不生动。

**⚠️ 一条容易搞错的边界：**
「含情脉脉」这类情绪状态词**不是要删的，它本身就是生动的、可用的**。
把它当禁词是错的。**它是「总」。**

---

## 一、正解：总—分结构（两种顺序都可以）

**一句话里既要给情绪或状态，也要写表情动作。顺序可以两种。**

### 顺序 A：总 → 分（先定调，后给证据）

> **他有些无奈又好笑，轻轻摇了摇头，嘴角跟着扯了一下。**

### 顺序 B：分 → 总（身体先动，情绪追认）

> **他微微皱眉，抿了一下嘴，那点无奈慢慢收了回去。**

**也可以「分—总」**：「他微微皱眉，抿了一下嘴，有些沮丧地缓慢摇头，
**配上一些形容词，还要有轻重缓急**。」

**顺序 B 特别像人**：人是先皱了眉，才意识到自己在难过。

**⚠️ 但请注意**：上面「有些沮丧地缓慢摇头」是**口述举例**；
落到**书面**时，**「总」要写成「带着 A 又 B」或「有些 A 又 B」**，
**不写成「A 地 + 动词」**——因为"地"直接修饰动作＝总结腔。
（依据：20 组范例里「总」一律是并置形状，详见 [影视化微表情写法.md](影视化微表情写法.md)）
身体先泄露，情绪后面**追认**自己。

| 什么时候 | 用哪种 | 为什么 |
|---|---|---|
| 情绪先到、动作是它的结果 | **总 → 分** | 观众先知道方向，再看证据 |
| 动作先起、人物后知后觉 | **分 → 总** | 身体先泄露，情绪追认自己 |
| 一句话要收住 | **分 → 总** | 收在情绪词上，有落点 |

### 轻重缓急：形容词挂在哪

**这是句子好不好听的关键。** 速度、幅度、犹豫都要挂上去：

| 维度 | 挂什么词 | 例 |
|---|---|---|
| **缓** | 缓慢 / 慢慢 / 缓缓 / 一点点 | 那点无奈**慢慢**收了回去 |
| **急** | 猛 / 急 / 一下 / 连忙 | **突然**别开脸 |
| **轻** | 微微 / 轻轻 / 稍稍 | **微微**皱眉 |
| **重** | 重重 / 使劲 / 硬生生 | **硬生生**把话咽回去 |
| **犹豫** | 迟疑 / 试探 / 半途 | **试探着**抬了下眼 |

**两条挂法**：
- **形容词要挂对地方**——「微微」是**轻**在动作上；「有些沮丧」是**状态**在总上。
- **轻急挂小动作，缓犹豫挂大动作。** 先快后慢＝犹豫，先慢后快＝决断。

```
✗ 他微微有些沮丧地轻轻缓慢地摇了摇头   （形容词挤成一团，读不出急缓）
✓ 他微微皱眉，抿了一下嘴，那点无奈慢慢收了回去
```

### 两个位置的活

| 位置 | 内容 | 例 |
|---|---|---|
| **总** | 情绪 / 状态 / 气质 —— 一个词定调 | 「有些无奈」「含情脉脉」「有些沮丧」「有些开心」 |
| **分** | 表情、动作、身体、重心 —— 让人看见 | 「轻轻摇了摇头」「眉梢轻抬」「笑出声」 |

**只有总**（含情脉脉地看着）→ **摆姿势**，模型不知道具体怎么演
**只有分**（眼睑微垂、呼吸变浅）→ **没方向**，像技术清单
**总＋分** → 模型既知道这是什么情绪，也知道这个情绪此刻长什么样

**「总」也是节拍器**：一场戏三到四拍，「总」可以每拍换（无奈 → 失落 → 硬撑），
「分」永远跟着换。**「总」不变而「分」在变，就演成了持续状态。**

### 合格的「总」词长得什么样

**要「语气副词 + 情绪词」**，副词把程度和犹豫带出来：

> 有些无奈 ｜ 有点沮丧 ｜ 带着点笑意 ｜ 勉强乐了一下 ｜
> 忽然认真起来 ｜ 像是松了口气

**不要光秃秃的情绪名词**：「悲伤」「愤怒」「喜悦」——那是标签，不是人在当下的样子。
**也不要文学化**：「情意像潮水漫上来」——那是抒情，不是方向。

## 二、要改的到底是什么

**不是情绪词，是「没有人的句子」。**

### 病根：只有部位，没有人

| ✗ 只有部位在某个状态（标本） | ✓ 有人在做一件事（总—分） |
|---|---|
| 眼泪**挂在**睫毛上 | **她哭得有点忍不住了**，泪顺着眼角滑下去 |
| 视线**压**过去**不挪开** | **她有些急**，眼睛跟着他的脸转，一步都不肯放 |
| 微皱眉 ｜ 眼睑微垂 ｜ 眉心轻收 | **她有些怔**，皱了皱眉，眼皮随即垂下去 |

**右列共同点**：先有一个「她怎样了」，再有身体在做什么。

### 带「着」的持续状态——换掉

**挂 着 ｜ 盯 着 ｜ 悬 着 ｜ 绷 着 ｜ 压 着 ｜ 维持 ｜ 处于 ｜ 呈现 ｜ 笼 着 ｜ 揪 着**

判断法：**动词后面能不能加「着」还不觉得怪？** 能加 → 那是状态，不是动作 → 换掉。

| ✗ 状态 | ✓ 在做的动作（前面可挂「总」） |
|---|---|
| 泪**挂**在睫毛上 | **她有点绷不住了**，泪顺着眼角滑下去 |
| 眼睛**盯**着 | **她舍不得挪开**，眼睛跟着他的脸转 |
| 手**悬**在半空 | **她犹豫了一下**，手抬到一半又收回来 |
| 肩**绷**着 | **她在忍**，肩往里收 |
| 话**压**着 | **她在克制**，话到嘴边又咽了回去 |
| 嘴角**浮**着一点冷笑 | **她带了点冷意**，嘴角往一侧扯起 |

### 自造词与「结果词」——不写

✗ 绷起来、打着转、翻着个儿、摩了两下、啾着、揪起身子 ——
**读者要在脑子里翻译一次才懂的，全部不写。用最短的实话。**

**还有一类是「结果词」**：它描述的是**观众看完之后下的判断**，不是演员能做出来的动作。
**眼睛亮起来** 就是这一类——「亮」不是动作，是结果。

| ✗ 结果词 | ✓ 换成动作 |
|---|---|
| 眼睛亮起来 | **眼睛微微一睁** |
| 眼睛暗下去 | **眼睑微垂** |

**判断法：这个词，演员做出来是什么样？** 说不出来 → 那是结果 → 换成动作。

### ★ 抽象判断——比状态词更隐蔽的一类

**「放平」「绷住」「松了」「平静下来」不是动作，是整张脸的结论。**
模型拿到它**不知道动哪里、往哪个方向**。**必须拆到肌肉与方向。**

| ✗ 抽象判断 | ✓ 拆成具体动作 |
|---|---|
| 整张脸放平 | 眉心展开，上眼皮落下来，嘴角跟着松 |
| 脸绷住 | 眉心往中间收，上眼皮撑开，嘴角往两边拉 |
| 表情松了 | 眉尾落下来，眼皮不再撑着，下颌往下沉 |
| 神情平静 | 眉心展开，呼吸匀下来，眼皮垂到自然的位置 |

**判断法：这个短语能不能落到「哪块肌肉、往哪个方向」？**
不能 → 你在写**观察结论**，不是写动作。

> **和「总」的区别要分清**（重要）：
> - `她像是认了` —— **允许**。这是**情绪方向**，是「总」。
> - `整张脸放平` —— **不允许**。这是**脸的结果判断**，没有方向、没有肌肉。
>
> 一句话：**「总」是心怎么了，「抽象判断」是脸怎么了。写前者，不写后者。**

## 三、三条写法规则

### 规则一：每句都要有「总」，位置随意

```
✗ 眼泪挂在睫毛上，嘴唇抿着
✓ 她有点撑不住了。轻轻吸了口气，睫毛轻颤，眼含泪花，嘴唇跟着抿了一下。
✓ 她轻轻吸了口气，睫毛轻颤，眼含泪花，嘴唇跟着抿了一下，她有点撑不住了。
```

**两个方向都行。** 第一种观众先知道方向；第二种身体先泄露、情绪后追认。

### 规则二：动作顺着人走下来，不按部位排序

**不要**「眉——眼——嘴——肩」一格一格填。**让第一个动作自然带出第二个。**

```
✗ 眉心轻收 ｜ 眼睑微垂 ｜ 嘴角微撇
✓ 他微微皱眉，抿了一下嘴，那点无奈慢慢收了回去
```

**部位是结果，不是起点。** 起点是「他现在怎么样、在做什么」。

### 规则三：不要竖线分隔，要连成句子

**「｜」是清单的形状，不是句子的形状。**

```
✗ 微皱眉 ｜ 眼睑微垂 ｜ 眉心轻收 ｜ 眼里盛着泪
✓ 她有些发怔，皱了下眉，眼皮随即垂下去。再抬起来的时候，眼里已经含着泪了。
```

**逗号连接同一动作内部的小停顿；句号断开不同动作。** 一段 2–4 句。

## 四、完整对照：含情脉脉

### ✗ 只有总（摆姿势）

```
女主含情脉脉地看着男主。
```

**问题**：模型只拿到一个词，会摆一张「好看的眼神」，然后定住。**没有戏。**

### ✗ 只有分（技术清单）

```
视线从他眼睛滑到嘴唇，又绕回来。睫毛压了压。呼吸变浅。
```

**问题**：动作都对，但**不知道这是爱、是试探、还是在忍着什么**。读起来像仪器读数。

### ✓ 总—分（总在前）

```
她有些舍不得，含情脉脉地看着他，嘴角先动了一下，笑意还没来得及展开。
视线从他眼睛滑到嘴唇，又绕回眼睛，像不敢停久。他说话的时候她点了一下头——
没听见内容，只是眼睛又亮了一层。
```

### ✓ 分—总（分在前）

```
她嘴角先动了一下，笑意还没来得及展开。视线从他眼睛滑到嘴唇，
又绕回眼睛，像不敢停久——她有些舍不得，含情脉脉地看着他。
```

**为什么「分→总」这一版也对**：
- **身体先泄露**：嘴角、笑意、视线，都是她**没打算**让人看见的
- **情绪后追认**：「她有些舍不得」落在最后，像她自己也是刚意识到
- **收在情绪上**：句子有落点，不是停在动作上

**为什么这样对**：
- **总在前**：「她有些舍不得」定调，「含情脉脉地看着」把气质给足
- **分跟上**：嘴角 / 笑意 / 视线 / 睫毛 / 点头 / 眼睛，逐层铺开
- **有轨迹**：眼睛→唇→眼睛，视线在走，不是「看着」
- **有错位**：点头不在内容点上——说明她走神了，这比任何形容词都像人
- **有先后**：「眼睛又亮了一层」是**后**发生的，不是同时

## 五、完整对照：v06 崩溃戏的重写

### ✗ 只有部位（我先前写的）

```
【顶】眼里盛着泪，视线往上看。一次眨眼后泪顺着眼角滑到腮边，
      肩膀跟着抽一下。眉心收紧，嘴张开却没出声。
```

**问题**：主语是「泪」「肩膀」「眉心」「嘴」——**人不见了**，
四个部位各写一笔，像四份报告拼在一起。

### ✓ 总—分

```
【顶】她嘴还硬着，人已经撑不住了。眼睛睁大，
      像是还没听完就已经信了。眼里盛着泪，她仰了下头想压回去。
      压不住，泪顺着眼角滑到腮边。肩膀跟着抽了一下，嘴微张，却没出声。
```

**为什么这样对**：
- **总**：「她嘴还硬着，人已经撑不住了」——一句给出双重状态（表里反差）
- **有主体**：「她」在做一系列事——睁眼、仰头、压、抽、嘴微张
- **有因果**：「想压回去」→「压不住」→「滑下来」，是**一个人在做决定**
- **动作自己接出来**：眼睛睁大→仰头→泪滑→肩抽→嘴微张，一条线走下来
- **没有裸状态**：没有「挂着」「盯着」「悬着」
- **没有破折号当拐杖**：并列动作断成句号

## 六、写作时的七个自问

写完一段，问自己：

1. **有没有「总」？**（没有 → 补一个，放前放后都行）
2. **这个「总」是不是光秃秃的标签？**（是 → 补成「带着 A 又 B」；✗ 不许用「A 地+动词」）
3. **「分」有没有动作在走？**（没有 → 补身体证据）
4. **有没有轻重缓急？**（全中速 → 给缓/急/犹豫挂形容词）
5. **动作是顺着走下来的，还是并列堆的？**（并列 → 改成接续）
6. **有没有口语白描 / 抽象状态 / 部位黑话？**（有 → 不合格，重写）
   → 跑 `python tools/check_prose_style.py <文件>` 自动查
7. **「反应—掩饰—泄露—回收」走完了没有？**（只写反应就落 → 不合格）

## 七、为什么这条对 AI 特别重要

DeepSeek 这类模型有个倾向：**在「抒情」和「代码化」两个极端之间跳。**

- 一放就写成散文（「情意像潮水漫上来」）——**不许**
- 一收就写成标签（「微皱眉 ｜ 眼睑微垂」）——**也不许**
- 只给情绪词（「含情脉脉地看着」）——**不够，会摆姿势**
- 只给部位动作（「睫毛压了压、呼吸变浅」）——**不够，没方向**
- 全是中速动作（「摇了摇头、皱了皱眉」）——**不够，没有轻重**

**中间那条路是：情绪和动作都要有，还要有快有慢。**

**这不是文风偏好，是生成质量的前提**：
模型拿到「有些沮丧地缓慢摇头」，会去演这个沮丧、这个慢；
模型拿到「四个部位四个状态」，只会摆姿势。
