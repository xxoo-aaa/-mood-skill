# 补强：肌肉调度与中断写法

> **★ 文体硬规则（不可协商）**：**必须要使用影视化 / 分镜式的微表情描写。**
> 本文件解决的是「先动哪儿、怎么收回」——
> **动作排对了，文体也必须对**（见 [影视化微表情写法.md](影视化微表情写法.md)）。

**本文件只写主文件里没有展开的细节。** 与主文件冲突时以本文件为准并注明理由。

## 一、肌肉调度：给表情排先后次序

写不出过程，常常是因为不知道**先动哪儿**。把一张脸拆成肌肉的先后手：

| 次序 | 肌肉 | 写什么 |
|---|---|---|
| 第一 | 皱眉肌 | 眉心收、挤出竖纹 |
| 第二 | 口轮匝肌 | 嘴唇失控——抖动、张开、抿住 |
| 第三 | 额肌 | 眉心展开、上眼皮落下来、嘴角松 |

**不要三块同时动**——同时动就回到「标准面具」。
**收尾必须是额肌先松**，脸才收得住；反过来写（先松脸再动嘴）会假。

> 例：「眉心聚拢，挤出两道浅浅竖纹」→「下唇失控地抖」→「眉心缓缓展开，上眼皮跟着落下来，嘴角松了」

**来源**：小红书·方棏木《AI文戏情绪冲突丨微表情教学拆解》。
原文称之为「情绪链的肌肉解构：先皱眉肌收缩，再口轮匝肌失控，最后额肌放松」。

## 二、排他指令：该不动的地方不动

不对称是「只动这一侧」**加上**「另一侧禁止参与」两句话。

```
她带着点笑意，只动一侧嘴角，另一边不动 ｜ 眼部不参与，笑意没扩散到眼底
```

写「苦笑」不能只写嘴角，要写清**它没能抵达哪里**：
未扩散到面部其他区域、全然没有抵达眼底。

**该不动的地方不动，比多动一处更像人。**
人类真实情绪从不纯粹、也从不完整；AI 感的一大来源是表情**过度对称、过度完成**。

**来源**：同上，第二条「命令矛盾与不完整，打破对称性」。

## 三、中断也是动作——「撤回」不是「静止」

**这条与「动作连着走」不冲突，必须分清：**

| | 写不写 | 为什么 |
|---|---|---|
| **无意义的静止** | ❌ 不写 | 到位后停着不动＝画面死了，AI 正好照做 |
| **有意图的撤回** | ✅ **要写** | 动作起来了、又生生收住——这个「收」本身就是戏 |

AI 生成的情绪往往太完整、太有始有终，而真人是在**中途断电**的。

写法：**先给出动作的起势，再写它在半路被压回去。**

- **她还想说**，话到嘴边又咽了回去
- **她有些舍不得**，似要张臂去抱，又收住
- **她有点怀疑**，摇头起了一半，慢下来，像忽然记起什么
- **她忍着**，眼眶泛红，泪在眼睑边缘积住
- **她犹豫了**，手抬起来，又落回膝上

**关键**：写清**是什么力量把它压回去**（忍、记起某件事、对方一个眼神），
不能只写「她忍住了」。**没有来由的中断＝另一个静态。**

**另一类对冲**：两种相反的情绪紧接出现，要标出时序——
> **她有点不甘心**，眼底的悲伤还没散，眼神紧接在之后变锐利

用「紧接在……之后」「同一瞬间」标注，**不用秒数**。

**来源**：同上，第四条「强调克制与中断，制造失序感」。

## 四、【明确排除】数值化幅度

外部方法里有一派主张「用数字杀死模糊」：
「振幅不足一毫米」「幅度不超过15度」「双肩内收2-3厘米，耗时1.5秒」「0.2秒的卡顿」。

**本项目不采纳。**

- 它的**诊断是对的**：「微微」「轻轻」确实容易被模型淡化为无。
- 但**药方不成立**：① 模型读不出「半度」「毫米」这种量级，等于往提示词里塞噪声；
  ② 与老规则的「准确、程度适宜的情绪引导」冲突，同一段里两套口径必乱。

**正确解法是「部位级排他」，不是数值**：

| 不写 | 改写成 |
|---|---|
| 眉心聚拢15度 | **她有些不悦**，皱了皱眉 |
| 双肩内收2-3厘米 | **她在忍**，肩往回收，胸口跟着塌下去 |
| 振幅不足一毫米的颤抖 | **她在硬撑**，下唇轻颤 |
| 眼睑抬升耗时1.5秒 | **她像是没反应过来**，眼皮抬起又垂下 |
| 0.2秒的卡顿 | **她犹豫了一下**，先快后慢，睁开前有点迟滞 |

效果相同——打破对称、防止整体化——且模型能执行。
