# 反例集 —— 写坏的样子长什么样

> **★ 文体硬规则（不可协商）**：**必须要使用影视化 / 分镜式的微表情描写。**
> 本文件列的**全部是违反这条规则的写法**。右列的「改法」就是这条规则的正确形状。
> 唯一文体标尺见 [影视化微表情写法.md](影视化微表情写法.md)。

**这份文件的用途：写完对一遍。** 每条都给出「错在哪」和「怎么改」。
不是词典，是**病历**——坏写法比好写法更容易被重犯，所以单独立档。

**来源标注**：
- `[素材]` = 从成片逐帧读出的实证对照
- `[导演]` = 导演明确点过的
- `[自查]` = 我写坏过、被扫出来或自己扫出来的

## 一、抽象判断 —— 最容易犯、最隐蔽

**病根：写的是「整张脸的结果」，不是哪块肌肉往哪儿动。模型读不出该动什么。**

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 整张脸放平 | 抽象结论，没有肌肉也没有方向 | 眉心展开，上眼皮落下来，嘴角跟着松 |
| 脸绷住 | 同上 | 眉心往中间收，上眼皮撑开，嘴角往两边拉 |
| 表情松了 | 同上 | 眉尾落下来，眼皮不再撑着，下颌往下沉 |
| 神情平静 | 同上 | 眉心展开，呼吸匀下来，眼皮垂到自然的位置 |
| 神色如常 | 观众视角的判断，不是演出来的 | 她照常抬眼看他，眼皮没多眨一下 |
| 表情一瞬间复杂 | 「复杂」不是动作 | 她嘴角往上走了一下，眉心却先收了 |
| 脸沉下来 | 抽象 | 下颌往里收，眉往中间压，目光往下落 |

**判断法：** 这个短语能不能落到「哪块肌肉、往哪个方向」？
**不能 → 你写的是观察结论，不是动作。**

> ⚠️ **别和「总」搞混**：
> - `她像是认了` —— ✅ 允许。这是**情绪方向**。
> - `整张脸放平` —— ❌ 不允许。这是**脸的结果判断**。
> **「总」是心怎么了；抽象判断是脸怎么了。写前者，不写后者。**

## 二、裸状态（静止体）—— 没有人的句子

**病根：只写部位在哪个状态，不写人在做什么。**

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 眼泪挂在睫毛上 | 只说明泪的位置，是标本 | 泪顺着眼角滑下去 |
| 眼睛盯着他 | 只有方向，没有事 | 眼睛跟着他的脸转 |
| 手悬在半空 | 停在半空，没有动作 | 手抬到一半 |
| 肩绷着 | 一种持续状态 | 肩往里收 |
| 话压在喉咙里 | 状态 | 话到嘴边又咽了回去 |
| 嘴角浮着一点冷笑 | 状态 | 嘴角往一侧扯起来 |
| 眼中含泪 | 状态 | 眼含泪花，她仰起头想压回去 |
| 他维持着笑容 | 状态词 | 他嘴角还留在那儿，笑意已经收干净了 |

**判断法：动词后面能不能加「着」还不觉得怪？** 能加 → 状态 → 换掉。

## 三、生硬词 —— 只给结果、不给方向

**病根：这些词是「结论」，模型拿到只会摆一个表情。**

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 她愣住了／呆住／僵住 | 只给结果，演员不知道怎么演 | 眼皮挣开往上翻，下巴抬起来，视线追上对方 |
| 眼睛睁得很大 | 只有大小，没有方向 | 眼皮挣开、眼白露出来 |
| 死死掐住 | 生硬 + 只给结果 | 指头收进掌心 |
| 目光注视着他 | 术语式，僵 | 视线落在他脸上没走 |
| 紧紧盯着 | 生硬 | 眼睛跟着他的脸转 |
| 眼神空洞 | 抽象 | 视线落在桌面上，没有跟着他动 |
| 眼睛亮起来 | 结果，不是动作——「亮」是看完才下的判断 | **眼睛微微一睁** |
| 面色铁青 | 结果状态 | 下颌收住，鼻翼随吸气撑开，眼睑压下来又抬起 |
| 指节泛白 | 结果状态 | 手把杯子推远，指头收拢又松开 |

## 四、自造词 —— 读者要在脑子里翻译一次

**病根：我自己发明、别人要靠猜的动词。**

| ✗ 反例 | 为什么坏 | ✓ 改法 |
|---|---|---|
| 绷起来 | 什么意思？绷哪儿？ | 肩往里收／眉心收紧 |
| 打着转 | 谁在转、转什么？ | 眼睛绕了一圈／心思绕回来 |
| 翻着个儿 | 含义不明 | （删掉，改写成具体动作） |
| 摩了两下 | 摩哪儿、为什么？ | 手指在杯壁上蹭了两下 |
| 啾着 | 生造 | （删掉） |
| 揪起身子 | 生造 | 上身缩了一下 |

## 五、计时器与数值 —— 都不是动作

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 他停了一拍 | 计时器不是动作；「拍」作量词禁用 | 他把话咽回去，喉头动了一下 |
| 不到半秒后 | 计时器 | 紧接在之后 |
| 顿了兩秒 | 计时器 | 他先没接话，眼睛垂了一下 |
| 眉心聚拢 15 度 | 模型读不出度数量级 | 微皱眉 |
| 双肩内收 2—3 厘米 | 同上 | 肩往回收，胸口跟着塌下去 |
| 眼睑抬升耗时 1.5 秒 | 同上 | 眼皮抬起又垂下 |
| 0.2 秒的卡顿 | 同上 | 先快后慢，睁开前有点迟滞 |

## 六、假动作与逻辑断裂

**病根：动作接不上，或者一个动作写两遍且力度矛盾。**

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 前镜「手送出」，后镜「松开手又甩出去」 | 同一动作写两遍，力度矛盾 | 只写一次：手送到胸口，指头松开，手落回去 |
| 她愣住，然后抬头 | 「愣住」是状态，不是动作 | 眼皮挣开往上翻，下巴抬起来 |
| 手抬起来悬空不动直到说完 | 悬空不动＝画面死了 | 手抬起来 → 随话意滑或收 → 收势 |
| 全文都是「停住」 | 到位即静止 | 改成滑、扫、挑、翻、转、压、牵、收 |

## 七、程序感 —— 一条线走完再走另一条

**病根：十部位被当成清单逐格填，人脸变成链条。**

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 微皱眉 ｜ 眼睑微垂 ｜ 眉心轻收 ｜ 眼里盛着泪 | 竖线分隔＝清单形状 | 她皱了下眉，眼皮随即垂下去。再抬起来时，眼里已经含着泪了 |
| 眉→眼→嘴→肩 逐格写一遍 | 按部位排序，不是按人在做什么 | 她笑得有点勉强，眉心先收了一下；笑意还没收起，眼皮已经垂下去了 |
| 一镜段落逗号堆 6 个以上 | 被切成清单条目，读起来程序化 | 并列动作用句号断开，每段 2—4 句 |
| 四个总词都一样 | 「总」不变而分在变＝演成持续状态 | 四拍的「总」各不相同 |
| 全部中速动作 | 没有轻重缓急 | 缓→急→重→缓 排开 |
| 十处同时动 | 木偶 | 错峰：一处先起，另一处跟上 |

## 八、只给总，或只给分

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 女主含情脉脉地看着男主（就这一句） | 只有总 → 摆姿势 | 见下「正确版」 |
| 视线从他眼睛滑到嘴唇，睫毛压了压，呼吸变浅（没有总） | 只有分 → 没方向，像仪器读数 | 补一个总：「她有些舍不得」 |
| 他微微有些沮丧地轻轻缓慢地摇了摇头 | 形容词挤成一团 | 他微微皱眉，抿了一下嘴，有些沮丧地缓慢摇头 |

**正确版（总—分）**
```
她有些舍不得，含情脉脉地看着他，嘴角先动了一下，笑意还没来得及展开。
视线从他眼睛滑到嘴唇，又绕回眼睛，像不敢停久。他说话的时候她点了一下头——
没听见内容，只是眼睛又亮了一层。
```

## 九、眼神与眼皮（主引擎，单独列反例）

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 她看着他 | 只有方向，没有路 | 她眼睛从他脸上滑到嘴唇，又绕回眼睛 |
| 她避开视线 | 没有返回时机 | 她眼睛往下一沉落到桌面，隔了一会儿才慢慢抬回来 |
| 她一直盯着不放 | 状态，且没有返回 | 她视线跟着他转，他偏头她也偏头，始终不肯先落回别处 |
| 眼皮垂下 | 一次到位＝交代 | 眼皮往下一沉，沉到一半又抬起来，再看回他时眼神已经稳了 |
| 全段只写了一次眨眼（或干脆没写） | 眨眼必须写 | 她说这句的时候眨得很快 |
| 眨眼次数写「眨三次」 | 数值化 | 写时机与频率 |
| 目光注视远方 | 落点不可见 | 落点必须是看得见的东西（眼睛／手／桌面／门口） |
| 眼和眉一起用力 | 同向用力＝标准面具 | 眼睁大↔眉抬起，眼微垂↔眉松开（此消彼长） |
| 移开视线就结束了 | 少了免费的戏 | 写清什么时候回来、回来时变没变 |

## 十、走位与姿态（场景逻辑）

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 人物从女主正前方过来 | 客厅茶几挡在女主正前方，过不来 | 从左侧绕到女主身边 |
| 隔一张茶几伸手指女主 | 隔茶几动作不成立 | 走到身边站定，一句写清在哪侧 |
| 女配跪下来抢婚纱 | 她是被全家宠的妹妹，跪是求人不合她 | 站着扑过来抢、弯腰抓、撑扶手发力 |
| 情绪突然大变但无触发 | 没有因果 | 写清是什么让他变的 |

## 十一、写「一整片一起动」（AIGC 专有）

**这一类是两个方向的反例并存**——该动的没写和写过头，都是错的。

### 方向一：该动的没写 = 呆若木鸡

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 只写「她沉默着」 | 一处都没动，像张照片 | 把十部位写够、写出两次变化 |
| 只给一句情绪词 | 没有身体，只有标签 | 补上部位级的过程 |
| 写「她走了」 | 只有结果没有过程 | 写肩的起伏、手指的收拢、呼吸的变化 |

### 方向二：写过头 = AI 把脸转过来

| ✗ 反例 | 错在哪 | ✓ 改法 |
|---|---|---|
| 「两侧嘴角一起压下去」 | **AI 会为让你看见，把脸转成正面** | 只写**一侧**嘴角，另一侧不动 |
| 「整张脸放松下来」 | 「整张脸」触发它转脸 | 写眉和嘴角松下来，不写「整张脸」 |
| 「她眼睛红了、泪在眶里」 | 大面积眼部动作 → 触发转身 | 换成肩、呼吸、手指 |
| 「她眼神一狠」配在手上 | 手上没有眼睛 | 写手指收紧、压住桌面 |

### 判断法

**这个动作，写出来是「一处」还是「一整片」？**

- **一处** → **写，而且要写够**（至少两次变化，否则呆若木鸡）
- **一整片** → **拆成一处，其余的写它的牵连**（肩、呼吸、手指、颈）

**核心**：**状态要继承，但只写一处。**
上一段在哭，这一段不能凭空平静——**内部状态连着，外部描写只落在写出来的那一处。**

> **为什么 AI 会转脸**：它分不清「描述现状」和「要求它动」。
> 你写「半边脸的嘴角压下去」，它可能理解为「要把嘴角给观众看」，于是转脸。
> **所以描述面铺得越宽，AI 转脸的风险越大。**
> **手部、背部这类地方，就不要写眼睛。**

## 用完怎么用

1. **写完一处情绪，先过第七节**（程序感），这一节命中率最高。
2. **再过第一节**（抽象判断）和**第二节**（裸状态）——这两节最隐蔽。
3. **涉及眼睛，必过第九节。**
4. **描述面铺得太宽（一整片一起动），必过第十一节**——这一步是 AIGC 专有的坑。
5. 扫不出来就上工具：`tools/scan_bare_state.py`，它会自动区分
   「讲规则的行」和「真在写作的行」。
