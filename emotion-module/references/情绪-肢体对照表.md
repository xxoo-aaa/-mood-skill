# 情绪 → 肢体 对照表

> **★ 文体硬规则（不可协商）**：**必须要使用影视化 / 分镜式的微表情描写。**
> 本表给的是**方向与主控部位**，落成句子时按那条规则写（见
> [影视化微表情写法.md](影视化微表情写法.md)）。

**这份文件补的是模块里最大的一个洞。**

十部位清单回答的是「**哪些部位要写**」；
这张表回答的是「**什么情绪下，哪个部位该往哪个方向动**」。

**没有这张表**，十部位就变成「十处各动一下」——动了，但动得不对。
**委屈和愤怒，肩颈的方向是相反的；掩饰和温情，手指的出路不一样。**
写反了，读出来就是另一个人。

---

## 怎么用这张表

```
① 定情绪类型（主类型，见主文件第 2 步）
② 来这张表查「这个情绪的肢体签名」
③ 签名给的是「方向 + 主控部位」，不是句子 —— 再按总—分结构写成句子
④ 过第 4 步四张禁用卡
```

**用法要点**：

- **先看「主控部位」** —— 每种情绪只有一个两处主控，**先写这两处，其余跟随**
- **再看「反向部位」** —— ⚠️ 这是最容易写错的地方，
  反向部位**要往相反方向走**，不要顺手一起写
- **「签名」不是台词脚本**，是方向说明书；具体幅度按情境给

## 一、委屈

| 项 | 内容 |
|---|---|
| **核心张力** | 想被理解 vs 说不出口 |
| **主控部位** | **嘴唇** ｜ **呼吸** |
| **方向** | 唇先动后收（张开要说→闭合抿住）；呼吸短、浅、压在胸上 |
| **反向部位** ⚠️ | **肩不是抬，是往里收**（向内塌，不是向上提） |
| **眼睛** | 想看对方又先垂下去；**泪先起于眶内，不急着掉** |
| **手指** | 收拢、抠住、抓紧手里的东西（**向外抓取 = 写错了**） |
| **落点** | 咽回去 / 收住；肩落下、目光滑开 |

**签名（可直接改用）**：
> **她话到嘴边又咽回去**，嘴唇轻轻动了一下就抿住了。吸的气短，没到胸口就停了。
> 肩往里收，胸口跟着塌。手把杯子攥紧。

**最常见的写错**：把委屈写成愤怒——肩抬起来、下巴扬起、眼睛瞪。
**委屈是往内收的，愤怒是往外顶的。这是两种情绪的分界线。**

## 二、愤怒

| 项 | 内容 |
|---|---|
| **核心张力** | 想反击 vs 还有顾虑 |
| **主控部位** | **下颌** ｜ **呼吸** |
| **方向** | 下颌收住、咬肌起棱；呼吸从鼻子里加重（往外顶） |
| **反向部位** ⚠️ | **肩不是收，是往上提**（挺起来，不是塌下去） |
| **眼睛** | 睁大、眼白露出来；**眉与眼反向**（眼睁大时眉抬起） |
| **手指** | 握拳、指节绷起；或用掌根压住桌面（**外放的力量**） |
| **重心** | 上身前迎半分——**身体先动，语言后到** |
| **落点** | 压住（硬生生咽回去）或断然（转身、摔门） |

**签名**：
> **她先是没吭声**，下颌收住，咬肌鼓起来。鼻息一下比一下重。
> 上身前迎了半分，话到嘴边又硬生生压回去，肩还提在那里没落。

**与委屈的分界**：愤怒的力量**往外走**（迎、提、顶、握），
委屈的力量**往里走**（收、塌、咽、攥）。

## 三、掩饰

| 项 | 内容 |
|---|---|
| **核心张力** | 想藏 vs 藏不住 |
| **主控部位** | **排他不对称** ｜ **眼神与眼皮错位** |
| **方向** | **只动一侧**（半边嘴角、半边眉），**另一侧明令不动** |
| **⚠️ 反向部位** | **笑先起来，眼睛慢半拍**——这是掩饰的签名动作 |
| **眼睛** | 「眼到、皮压住」＝克制（想看看，又不敢看） |
| **呼吸** | 屏一下再呼出来（**先停，再放**） |
| **手指** | 找一个无意义的动作做（摸杯沿、理袖口）——**手在替脸分神** |
| **落点** | **破绽留下**：笑意不扩散到眼底 |

**签名**：
> **她像是没事**，笑先起来，只动一侧嘴角，另一边没动。眼睛慢了半拍才跟上，
> 笑意没到眼底。手在杯沿上摸了一下，又收回来。

**关键**：掩饰**不能写成功**。写成功＝平静，那就没有戏了。
**破绽必须留下**（哪一处没跟上），这是「掩饰」这个情绪的全部价值。

## 四、温情

| 项 | 内容 |
|---|---|
| **核心张力** | 想靠近 vs 有所保留 |
| **主控部位** | **眼神路径** ｜ **嘴的上半部** |
| **方向** | 视线在对方脸上**走一段路**（眼→唇→眼），**不敢停久** |
| **反向部位** ⚠️ | **眼部不参与其他表情**——笑意只在嘴，**不许扩散到眼底以外的地方**（要写清它到哪儿为止） |
| **眼睛** | 「眼走、皮慢半拍」＝舍不得；眨眼比平时慢 |
| **呼吸** | 呼出去的时候肩跟着落（**松下来**，与委屈的压住相反） |
| **手指** | 想伸出去、到一半收住（**有意图的撤回**） |
| **落点** | 靠近半步 / 或收住不说 |

**签名**：
> **她有些舍不得**，含情脉脉地看着他，嘴角先动了一下，笑意还没来得及展开。
> 视线从他眼睛滑到嘴唇，又绕回眼睛，像不敢停久。

**与掩饰的分界**：掩饰是**笑先起、眼慢半拍**（假的）；
温情是**眼先走、嘴后跟**（真的，但不敢久留）。**顺序一反，意思就反了。**

## 五、四类情绪横向速查 ⚠️ 别记混

| | 委屈 | 愤怒 | 掩饰 | 温情 |
|---|---|---|---|---|
| **力量方向** | 往内收 ⬇️ | 往外顶 ⬆️ | 藏一半 | 试探着靠近 |
| **肩** | **往里收、塌** | **往上提、挺** | 端着不动 | 呼气时落下 |
| **下颌** | 往下沉 | **收住、起棱** | 抿住 | 放松 |
| **眼睛** | 先看后垂 | 睁大、露白 | 慢半拍跟上 | 走一段路 |
| **手指** | 收拢、抓紧 | 握拳、压桌 | 找无意义动作做 | 伸一半收回 |
| **呼吸** | 短、浅、压住 | 加重、往外顶 | 先屏后放 | 呼出时松开 |
| **落点** | 咽回去 | 压住/断然 | **破绽留下** | 靠近半步/收住 |

**这张表要背下来的两条**：

1. **委屈 ⇄ 愤怒，肩是反的**（收 vs 提）。这是最容易写混的一对。
2. **掩饰 ⇄ 温情，眉眼顺序是反的**（笑先起 vs 眼先走）。这是第二容易写混的一对。

## 六、其余情绪（按同一套逻辑推，不是实测）

上面四类有实证与共识支撑。其余情绪按**「力量方向 + 主控部位」**同一逻辑推：

| 情绪 | 力量方向 | 主控部位 | 肩 | 眼 |
|---|---|---|---|---|
| 恐惧 | 往回缩 | 呼吸 ｜ 眼神 | 往内缩、僵 | 定在一处不敢移 |
| 失望 | 往下坠 | 眉尾 ｜ 肩 | 落下 | 视线离开对象 |
| 决绝 | 往定住 | 下颌 ｜ 重心 | 稳住不动 | 不返回（返回时机＝不回头） |
| 惊讶 | 往外弹 | 眼皮 ｜ 呼吸 | 一顿 | 睁大、忘了眨 |
| 尴尬 | 想走 | 眼神 ｜ 手指 | 一侧偏开 | 找地方放（看别处） |
| 心疼 | 往里揪 | 眉 ｜ 呼吸 | 前倾 | 追着对方的伤处看 |

**注意口径**：这张表是**从四类主型的逻辑推出来的**，**不是实测**。
用法与上面四类相同，但**先按上面四类练准**。
