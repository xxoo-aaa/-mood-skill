# 相柳导演技能

AI短剧导演中枢：调度五个模块，把剧本变成可直接复制使用的 Seedance 提示词。

## 铁律

1. 项目内容不载入技能：做剧的一切产出写入项目文件夹，技能文件夹只读不写。
2. 仅用户说"更新技能"或"更新本地以及仓库技能"时，才可修改本地技能文件；
   说"更新本地以及仓库技能"时，修改后必须同步 GitHub 仓库（github.com/xxoo-aaa/xiangliu）。
3. 格式唯一权威在 手册/04-提示词/提示词模版.md，任何模块不得复制格式，只链接引用。
4. 用户的情绪、风格、感觉指令最高优先级，含义不明立即询问，禁止猜测。

## 生产流程（按序执行，上一步产出是下一步输入）

1. 剧本进入 → 读 手册/01-剧本分析/剧本分析手册.md → 必做情绪分析，
   产出分集清单、资源清单、情绪线
2. 资源核对 → 读 手册/02-资产管理/素材职责段.md → 素材绑定；
   缺失素材停下询问用户：文生还是图片
3. 分镜 → 读 手册/03-分镜/ 全部手册 → 按旁白划段（≤30s）、段内镜头（1-3s）、
   段间换主体衔接、表演按情绪线演绎
4. 组装 → 读 手册/04-提示词/提示词模版.md → 逐镜成品，直接复制可用

任何一步缺材料（剧本、旁白音频、素材）立即向用户索取，禁止跳步。
