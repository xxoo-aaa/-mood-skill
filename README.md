# 十月导演技能

一个中心路由，调度各个环节。

## 结构

```
                十月（总路由）
                判断 → 转交 → 报告
                     │
              情绪表演（已建）
                     │
              其余环节 —— 待建
```

## 已建成

| 环节 | 目录 | 负责什么 |
|---|---|---|
| **总路由** | `director-october/` | 判断这活归哪一环、转交、报告 |
| **情绪表演** | `emotion-module/` | 情绪类型、四拍弧线、十部位联动、眼神与眼皮、句法 |

## 安装

把 `director-october/` 和 `emotion-module/` 两个目录放进技能目录即可：

- WorkBuddy：`~/.workbuddy/skills/`
- CodeBuddy：`~/.codebuddy/skills/`

## 用法

说「**十月**」启动，或直接给情境要情绪写法。

## 说明

- 情绪模块**只管情绪**，不写镜头、景别、机位、时长。
- 环节清单陆续补齐，未建成的环节碰到时明确报缺。
